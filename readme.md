# 项目说明

## 一、问题来源及任务目标

滚动轴承广泛用于电机、泵、风机和机床。通过振动时序区分健康状态与内圈、外圈、滚动体缺陷，是旋转机械状态监测的典型工程任务。在低信噪比、调制混叠和有限测量时间等条件下，单一频谱峰或经验阈值不一定足以证明故障类型。

本项目使用美国凯斯西储大学（Case Western Reserve University，CWRU）轴承实验数据中的四组记录，交由 Agnes Harness（AGH）中的 Agnes 模型完成数据读取、分析方法选择、Python 代码编写和执行、结果复核及诊断报告生成。目标不仅是判断类别，还要形成可检查的计算与证据链，并记录诊断失误及其局限。

## 二、数据与任务范围

使用四份 `.mat` 数据，仓库文件名为 `samples/sample_A.mat` 至 `sample_D.mat`。被测对象为 SKF 6205-2RS JEM 电机驱动端轴承，负载条件为 2 HP。A/C/D 采样率为 12,000 Hz；B 采样率为 48,000 Hz。A、C、D 采用各自记录的 RPM，B 采用约 1750 RPM 标称值。

本项目只提交轴承振动诊断。此前独立进行的电路故障实验不属于本项目的提交范围。

## 三、核心方法与 AGH 作用

任务入口是 `TASK.md`，实验条件由 `SAMPLE_PARAMETERS.md` 提供。Agnes 在 AGH 内获得工作目录文件及 shell/Python 工具能力，读取 MAT 文件、检查通道和统计量、编写并运行信号分析脚本，使用频谱、包络与振动特征频率进行多轮判断和复核，并生成可读报告与量化结果。

项目并未调用已经训练好的故障标签分类模型，也没有把 Agnes 简化成只负责生成展示文案的组件。AGH 承担的是实际分析和工具执行流程；NumPy、SciPy 和 Matplotlib 承担数值计算与可视化。

## 四、可核查的实验结果

依据公开仓库的 `results/diagnosis.md`、`results/summary.json` 及 `GROUND_TRUTH.md`：

| 样本 | 原实验标签 | Agnes 最终输出 | 记录中的置信度 | 对照结果 |
|---|---|---|---:|---|
| A | 外圈缺陷 | outer_race | 0.88 | 一致 |
| B | 正常 | normal | 0.85 | 一致 |
| C | 内圈缺陷 | inner_race | 0.88 | 一致 |
| D | 滚动体缺陷 | normal | 0.68 | **误判** |

四样本中有三份分类与实验标签一致，D 的最终结论是一次假阴性。这里的 3/4 仅描述此四条记录的结果，不代表一般化识别准确率，也不构成统计意义上的性能基准。

在 D 的复核过程中，模型针对轴承 BSF（滚动体自转频率）公式与轴转谐波混叠问题更正了分析代码，但最后仍把这一具有植入缺陷的记录判为正常。低峭度、某频点缺少峰、或者经验阈值未达到，只能说明所选检测方法未识别到清晰签名，不能独立证明物理轴承健康。这是本次实验保留的主要失败案例。

## 五、验证方法与边界

1. **来源验证**：通过 CWRU 原始记录号及实验标签对照四份数据；公开仓库的 `GROUND_TRUTH.md` 供评委核查。
2. **计算验证**：可运行 `freq_module.py` 复核轴承几何特征频率；可运行 `final_diagnosis.py`、`final_check.py` 等重算中间分析指标，并与 `results/` 中量化结果比对。
3. **执行验证**：以 AGH 的真实会话、工具调用、脚本产物、文本输出、频谱图为证据。`agh-diagnostics-*.zip` 的具体内容及是否包含完整逐步会话，需由参赛者核查后准确说明。
4. **异常验证**：保存修复 BSF 公式、复核 2×轴转频干扰等分析过程；同时保留样本 D 的错误判断，不作事后改写。
5. **解释边界**：公开文件名虽采用 A–D，MAT 内仍包含原始变量编号；且仓库公开了标签映射。因此本仓库适用于结果复核，但不能直接称为完全不可反查的严格盲测环境。

## 六、技术价值与可扩展方向

本项目展示了 AGH 在工程数据上的任务理解、调用通用计算工具、形成中间证据、根据反馈调整分析及记录失败的能力。可扩展方向包括更稳健的多频带包络分析、阈值标定、跨通道一致性检验、不确定性校准，以及对更多真实记录的外部验证；这些尚未完成的工作不计入本次交付成果。
