# 轴承振动诊断报告（公式修正版 + 最终检查）

> 本版修正了前序版本中的两处错误：
> 1. **BSF 公式**：正确为 `BSF = ½·(PW/d − (d/PW)·cos²α)·fr`（**不含 N**），α=0° 下 rpm=1754 时 = 68.90 Hz。前序误用 83.x Hz（套 N/2）与 125.x Hz（仍含 N）。
> 2. **2×fr 轴谐波污染**：FTF×5 ≈ 58.2 Hz 与 2×轴转频重合，该位置的高比值是**轴系 2nd-order 谐波**（跨样本共有的系统性背景），**不属任何轴承特征**。本版已将其从特征列中剔除。
> 3. **漏报 FTF 强列**：A/C 的 4×FTF、6×FTF 位置存在强且纯净的谐波列，前序未识别。

## 权威特征频率（freq_module.py，α=0°，N=9，d=7.940mm，PW=39.040mm）

| 特征 | 公式 | 说明 |
|---|---|---|
| FTF | ½(1−d/PW)fr | 保持架，跨样本 2×fr 重叠区需剔除 x5 |
| BPFO | N/2(1−d/PW)fr | 外圈 |
| BPFI | N/2(1+d/PW)fr | 内圈 |
| **BSF** | **½(PW/d − d/PW·cos²α)fr** | **滚动体自转，不含 N** |
| 2×fr | 2·fr | **轴系 2nd-order 谐波，非轴承特征，判读时剔除** |

## 判读规则（最终版）

- 取**纯净特征列**（剔除 2×fr 位置）的完整性 = 1~4 阶中比值 >3 的占比。
- 某特征主导判据：纯净列完整性 ≥0.5 且基频 lead >10，且跨通道同向。
- 故障阈值：基频包络比 ≥10 视为显著；远端通道（FE/BA）比 <1 为强否定证据。
- 滚动体正常判据：BSF 各阶 <1 + BPFO±fr 无调制边带 + 时域近高斯。

## 样本 A — 外圈故障（outer_race），置信度 0.88

- 数据：X236_DE/FE/BA，10.2 s，fs=12,000 Hz，记录 rpm=1748
- 特征频率：BPFO=104.44，BPFI=157.76，BSF=68.66，FTF=11.60，2×fr=58.27 Hz
- **主导特征 BPFO（DE x1=582.9，BA x1=1315，FE x1=306.8）——三通道同向**
- **新发现强 FTF 列**：4×FTF=46.4 Hz 处 DE 比 358.6（纯净，远离 2×fr）；提示外圈缺陷敲击伴随保持架成分
- BPFI/BSF 全 <2.8（排除内圈/滚动体）
- 时域：DE kurtosis=23.2、Crest=11.7、分段峰度 20/20>10（强间歇冲击，全通道一致）
- **结论**：`outer_race`（外圈缺陷 + 保持架伴随调制）
- 不确定性：FTF 强列使"纯外圈"把握略降；BPFO 仍绝对主导。

## 样本 B — 正常（normal），置信度 0.85

- 数据：X098/X099 各 DE/FE，10.1 s，fs=48,000 Hz，标称 rpm≈1750（无记录 RPM）
- 特征频率：BPFO=104.56，BPFI=157.94，BSF=68.74，FTF=11.62，2×fr=58.33 Hz
- **所有特征纯净列 <1.3**（全四通道），无一达阈值
- 唯一略高的 FTF x5=9.8 已识别为 2×fr 轴谐波污染，剔除后真实 FTF x1~x4 <1.1
- 时域：四通道 kurtosis 2.87~2.93（近高斯），0/20 分段>10
- `ans=1` 弱参考旁证
- **结论**：`normal`（最干净）

## 样本 C — 内圈故障（inner_race），置信度 0.88

- 数据：X211_DE/FE/BA，10.2 s，fs=12,000 Hz，记录 rpm=1752
- 特征频率：BPFO=104.68，BPFI=158.12，BSF=68.82，FTF=11.63，2×fr=58.40 Hz
- **主导特征 BPFI（DE x1=290.1，BA x1=116.1，FE x1=73.8）——三通道同向**
- **新发现强 FTF 列**：x1=37.3、6×FTF=69.8 Hz 处 DE 比 36.5（纯净）；内圈缺陷在 2HP 轻载下常伴保持架调制

- 时域：DE kurtosis=8.06、Crest=7.41；分段峰度 0/20（间歇冲击弱于 A，符合内圈轻载特性）
- 自适应：BPFI 最佳锁定 157.76 Hz @ rpm=1748（比 1526），提示实际转速略低于记录值 1752
- **结论**：`inner_race`（内圈缺陷 + 保持架伴随调制）

## 样本 D — 正常（normal），置信度 0.68

- 特征频率：BPFO=104.80，BPFI=158.30，BSF=68.90，FTF=11.64，2×fr=58.47 Hz
